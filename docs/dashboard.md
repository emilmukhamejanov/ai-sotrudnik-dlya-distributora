# Дашборд (этап 4)

Веб-интерфейс к агенту: React 19 + Vite + TypeScript, код — `frontend/`. Собранный дашборд отдаёт тот же
FastAPI-сервер, что и API (`http://127.0.0.1:8000/`), поэтому для запуска Node.js не нужен — только для сборки.

## Диалог

- Вопросы к агенту, ответы в markdown, ссылки на пункты документов, таблица результата SQL и сам запрос.
- Действие в Битрикс24 приходит карточкой «что / ответственный / срок» с кнопками «Создать в Битрикс24» и
  «Отменить» — без нажатия ничего не создаётся (`POST /chat/{thread}/confirm` с `action_id`).
- Статусы, которые важно не пропустить — создано в Битрикс24, передано сотруднику, отклонено защитой, отменено, —
  отмечены «печатью», как документы в бухгалтерии.
- Быстрые вопросы по четырём направлениям: цифры из 1С, регламенты, задачи в Битрикс24, вопросы на казахском.

## Путевой лист ответа

Справа — трасса выбранного ответа: остановки графа по порядку (защита, роутер, поиск по документам, запрос к
данным, формулировка, подготовка и подтверждение действия, передача человеку). Для каждой — время, модель и токены,
а в деталях:

- роутер — почему выбран маршрут и как он переформулировал вопрос для поиска;
- поиск по документам — найденные пункты с оценкой RRF, пометка внешних документов и что вырезала защита от
  prompt injection;
- запрос к данным — все попытки SQL и ошибки проверки или базы;
- защита — какие ПДн скрыты до отправки в модель (без самих значений).

Сверху — итог хода: время, токены и стоимость, с разбивкой по моделям (роутер на Haiku в десятки раз дешевле).

## Качество и расходы

- История прогонов evals из `var/evals` (график «пройдено вопросов по прогонам»), точность по категориям и
  причины провалов — как их записала автоматическая проверка, вместе с ошибками инструментов из трассы.
- Кнопка «Запустить проверку» — прогон всех 35 вопросов на настоящей модели с прогрессом; перед запуском
  дашборд предупреждает о времени и стоимости.
- Расходы прогона (стоимость, в среднем за ответ, медиана и p95 времени, токены) и расходы текущего диалога.

Стоимость считается по моделям: цены Claude Sonnet 5.5 и Haiku 5.5 зашиты по умолчанию
(`backend/src/dala_agent/pricing.py`, по странице цен на 18.11.2026), для других моделей —
`LLM_PRICE_INPUT_PER_MTOK` / `LLM_PRICE_OUTPUT_PER_MTOK` в `.env`.

## Оформление

Идея — рабочий документ дистрибьютора: ответ агента как накладная, трасса как путевой лист с остановками,
статусы как фиолетовые печати. Шрифт Golos Text (кириллица, включая казахские буквы), код — JetBrains Mono;
шрифты встроены в сборку. Цвета двух серий графиков (основная модель и роутер) проверены на различимость при
нарушениях цветовосприятия и на контраст; есть тёмная тема (по настройке системы), адаптив до телефона,
видимый фокус клавиатуры, уважение к «уменьшить движение».

## Разработка

```bash
make api        # API на :8000
make ui-dev     # дашборд на http://localhost:5173 с прокси к API
cd frontend && npm run typecheck && npm test
make ui         # сборка в frontend/dist — её отдаёт make api
```
