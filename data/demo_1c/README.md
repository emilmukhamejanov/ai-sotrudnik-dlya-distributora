# Демо-выгрузка «из 1С» (синтетические данные)

CSV сгенерированы командой `make data` (seed фиксирован, результат воспроизводим). Не редактируйте
файлы вручную: тест `test_committed_csv_is_up_to_date` сверяет их с выводом генератора.

Кодировка UTF-8, разделитель — запятая, первая строка — заголовок, пустое поле — `NULL`,
даты в формате ISO, суммы в тенге с НДС. Описание полей — в `db/sql/001_erp.sql` и
[docs/data_model.md](../../docs/data_model.md).

Компания, клиенты, сотрудники, ИИН/БИН и телефоны вымышлены. ИИН и БИН имеют корректную
контрольную цифру, чтобы проверять маскирование ПДн на правдоподобных данных.
