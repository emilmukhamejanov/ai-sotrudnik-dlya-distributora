# Опубликованные прогоны evals

Отчёты настоящих прогонов агента (Claude Sonnet 5.5 + Haiku 5.5) на 35 эталонных вопросах. Они лежат
в репозитории, чтобы история качества была видна и в публичном демо, где запуск evals выключен.
Новые прогоны сохраняются в `var/evals` (в git не попадают); удачные можно переложить сюда.
